# Investment Postmortem Example

## User Prompt

```text
帮我复盘一次投资亏损，看看问题出在哪里。
```

## InvestFlow Route

`postmortem`

## Required Inputs

- 标的：
- 买入时间：
- 买入理由：
- 仓位比例：
- 退出时间或当前状态：
- 实际结果：
- 投资期间出现的新信息：

## Postmortem Output

## 原始决策

- 当时的 thesis 是什么
- 当时使用了哪些数据
- 哪些风险被识别，哪些风险被忽略

## 实际结果

- 结果是否来自 thesis 被证伪
- 是否存在市场整体因素
- 是否存在执行或仓位问题

## 错误来源

- 信息：关键数据缺失或过期
- 分析：把故事当成 thesis
- 情绪：FOMO、锚定成本、拒绝止损
- 执行：没有按计划复盘
- 仓位：单一标的暴露过高

## 下次行动规则

- 每个 thesis 必须写失效条件
- 每个重仓必须写最大亏损边界
- 每次财报或重大事件后必须复盘一次

This example is for research workflow demonstration only and is not investment advice.
