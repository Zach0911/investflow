# Stock Research Example

## 用户问题

```text
英伟达现在还能买吗？
```

## InvestFlow 首步响应

## 投资判断

信息不足

## 需要补充的信息

1. 标的：代码 / 市场 / 资产类型
2. 周期：短线 / 中线 / 长线
3. 仓位：无仓 / 轻仓 / 重仓 / 占总资产比例
4. 风险：最大可接受亏损比例或金额

## 为什么不能直接回答

- 当前价格、估值、财报、市场环境都具有时效性。
- 用户仓位和风险承受能力未知。
- “还能买吗”可能代表买入、加仓、追涨或长期定投，决策含义不同。
