# ETF Long-Term Review Example

## User Prompt

```text
这个 ETF 适合长期持有吗？
```

## InvestFlow Route

`investment-briefing` -> `valuation-check` -> `risk-review`

## Required Inputs

- ETF 代码、市场、币种
- 跟踪指数或策略
- 费率
- 持仓集中度
- 流动性
- 溢价 / 折价
- 跟踪误差
- 用户投资周期和仓位比例

## Review Output

## 投资判断

信息不足 / 谨慎观察 / 持有但设退出条件

## 关键依据

- 指数或策略暴露是否符合用户长期计划
- 前十大持仓集中度是否可接受
- 费率、流动性和跟踪误差是否影响长期体验
- 当前估值或市场环境是否显著提高回撤风险

## 反方最强质疑

- ETF 可能集中暴露于单一行业、风格或少数巨头
- 长期持有不等于无风险，最大回撤可能超过用户承受范围
- 汇率、利率、估值压缩或政策风险可能影响结果

## 复盘条件

- 指数编制规则变化
- 持仓集中度明显上升
- 用户资产配置目标变化
- 回撤接近最大可接受亏损

This example is for research workflow demonstration only and is not investment advice.
