# Losing Position Review Example

## User Prompt

```text
我持有某只股票已经亏了 25%，要不要补仓？
```

## InvestFlow Route

`investment-briefing` -> `risk-review` -> `dialectic-investment-decision`

## First Response

## 投资判断

信息不足

## 需要补充的信息

- 标的：代码 / 市场 / 资产类型
- 当前仓位：占总资产比例、单一标的集中度
- 投资周期：短线交易、中期波段、长期持有
- 最大可接受亏损：比例或金额
- 原始 thesis：当初买入理由
- 当前数据：最新价格、财报、公告、重大新闻的来源和时间

## 风险审查重点

- 补仓是否只是摊低成本，而不是 thesis 更强
- 基本面是否恶化
- 估值是否仍然偏高
- 单一标的仓位是否过度集中
- 用户是否有流动性压力

## 后续输出要求

如果信息补齐，最终判断不能只写“补仓”或“不补仓”。必须包含：

- 仓位上限
- 失效条件
- 退出 / 复盘条件
- 反方最强质疑

This example is for research workflow demonstration only and is not investment advice.
