# Risk Review

## Overview

Run the strongest opposing case before any investment view is treated as usable.

## Required Inputs

- Original thesis or proposed action
- Instrument and horizon
- Position size or intended exposure
- Known data limitations
- User risk tolerance

## Workflow

1. Restate the original thesis fairly.
2. Build the strongest反方 case.
3. Check fundamental, valuation, liquidity, macro, regulatory, governance, and event risks.
4. Check behavioral risks: FOMO, anchoring, averaging down, overconfidence, and concentration.
5. Identify what would make the original thesis unacceptable.
6. Recommend how the thesis should be revised, reduced, delayed, or abandoned.

## Output Format

```markdown
## 原始观点

## 反方最强质疑

## 主要风险

## 行为偏差

## 原观点是否仍成立

## 修正建议
```

## Common Mistakes

- Giving generic risk warnings.
- Attacking a weak version of the thesis.
- Omitting concentration and max-loss risk.
