# Thesis Builder

## Overview

Convert research into a thesis that can be tested, challenged, and reviewed later.

## Required Inputs

- Research brief
- Instrument and asset class
- Horizon
- Intended decision
- Current data basis
- Existing position and risk tolerance if the thesis supports action

## Workflow

1. State the core thesis in one sentence.
2. Separate facts from assumptions.
3. Identify expected return drivers.
4. Define catalysts or milestones.
5. List the key variables to track.
6. Define what would invalidate the thesis.
7. Route to `risk-review` before any actionable conclusion.

## Output Format

```markdown
## 核心 Thesis

## 已知事实

## 关键假设

## 收益来源

## 催化路径

## 需要跟踪的数据

## 失效条件

## 下一步风险审查
```

## Common Mistakes

- Writing a narrative instead of a falsifiable thesis.
- Missing the condition that proves the thesis wrong.
- Ignoring position size when the thesis becomes actionable.
