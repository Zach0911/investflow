# 多 Agent 投研分工

## 任务概览

- 标的：
- 用户决策：
- 投资周期：
- 最终交付物：

## Data Agent

- 读取只读数据源。
- 标注数据来源、时间戳和是否为示例数据。
- 不解释为投资建议。

## Company Agent

- 分析商业模式、财务质量、竞争位置和治理风险。
- 区分事实、假设和缺失数据。

## Valuation Agent

- 检查估值、关键假设和情景边界。
- 不输出 standalone 买入 / 卖出。

## Risk Agent

- 写出反方最强质疑。
- 检查行为偏差、集中度、流动性和下行风险。

## Arbiter Agent

- 汇总前置 Agent 输出。
- 只输出有边界的判断标签。
- 必须包含仓位与风控、失效条件和复盘条件。

## 交接规则

- 每个 Agent 必须注明数据来源和时间戳。
- 如果关键数据缺失，Arbiter Agent 必须降低结论强度。
- 任何 Agent 都不得执行交易或连接券商账户。
